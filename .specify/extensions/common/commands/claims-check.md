# Claims check

Go through the text named below and label every factual or causal claim:

- **verified**: you ran it or read the code, and say how;
- **documented**: a source says so, and you link it;
- **inference**: your reasoning, stated as such;
- **unknown**: not established.

$ARGUMENTS

Write the result next to the text as `<name>.claims.md`. A claim labelled unknown that the text states as fact is a finding.
