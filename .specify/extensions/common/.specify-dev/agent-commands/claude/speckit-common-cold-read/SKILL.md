# Cold read

Read the text named below as someone who did not write it and has none of its background.

$ARGUMENTS

Write `<name>.cold-read.md` with:

1. what you understood it to say, in three sentences;
2. every place you had to guess, with the words that made you guess;
3. every term you could not understand from the text itself.

Do not suggest rewrites. Report only.
