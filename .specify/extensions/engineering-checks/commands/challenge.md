# Challenge

The stock clarify, checklist and analyze steps already check the spec is complete and consistent. Do not repeat them.

Attack the idea itself. For the current spec, find:

1. assumptions that could be wrong, and what happens if they are;
2. failure modes the spec does not handle;
3. risks it does not state;
4. a simpler way to reach the same outcome, if there is one.

$ARGUMENTS

Write `.specify/reviews/challenge.md`, one finding per heading in the form `### F<n> <title>` (F1, F2, …), each with what would settle it. End with `Open findings: N`.
